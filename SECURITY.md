# Security Policy

Do not open a public issue containing a suspected vulnerability, credential,
customer identifier, raw telemetry, or evidence.

For a repository vulnerability, use GitHub's private vulnerability-reporting
or security-advisory flow when available. For organization-level coordination,
contact `github@lowcountrycyber.net` with a minimal description and arrange a
private evidence-transfer method before sharing sensitive material.

Never send secrets, private keys, tokens, customer evidence, or production
configuration through an ordinary issue or pull-request comment.
